Diretrizes Críticas de UX & Acessibilidade

Acessibilidade WCAG 2.1 (Contraste 4.5:1)
Contraste mínimo para texto normal. Nunca remover focus-ring em elementos interativos e sempre fornecer aria-labels em botões só com ícone.
Touch Targets (Mínimo 44×44px)
Área de toque segura com espaçamento de 8px+ entre botões móveis. Feedback visual instantâneo a cada interação.
Performance Visual & CLS (< 0.1)
Reservar dimensões de imagens (evitar saltos de layout), usar formatos WebP/AVIF e aplicar carregamento preguiçoso (lazy loading).
Arquitetura de Tokens em 3 Camadas
Primitivos (valores brutos) → Semânticos (propósito de uso) → Componentes (específicos do elemento).
